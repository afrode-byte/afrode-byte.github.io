About

I am a Brazilian Web Application Penetration Tester with a background in Computer Engineering and a strong interest in offensive security research.

My work focuses on evaluating the security of modern web applications through structured, manual testing methodologies. Rather than relying solely on automated scanners, I prioritize understanding how applications are designed, how users interact with them, and how attackers can abuse those interactions.

I use manual testing to understand the full application attack surface, from common vulnerability classes to subtle logic flaws, unusual behaviors, exposed assumptions and feature-specific abuse cases.

My approach combines the OWASP Web Security Testing Guide, PortSwigger’s Burp Suite testing workflow, bug bounty practice, practical labs, continuous research and lessons learned from each penetration test. I see web hacking as a constant accumulation of techniques, observations and methodology improvements.

I also learn a lot from studying vulnerability research published by other security researchers. Work from researchers such as James Kettle has influenced how I think about web attack surfaces, edge cases, parser behavior and the value of deeply understanding how applications process data.

I believe effective penetration testing is not only about discovering vulnerabilities, but also about understanding application behavior, identifying security assumptions and providing actionable recommendations that improve the overall security posture.

Outside professional engagements, I continuously study emerging attack techniques, modern web technologies and offensive security research to improve both my technical knowledge and testing methodology.

Tools & Methodology Link to heading

I commonly work with Burp Suite, browser developer tools, manual request analysis, payload testing, documentation review, OWASP WSTG-based checklists and PortSwigger’s testing workflow. My methodology also evolves through bug bounty practice and by studying high-quality public vulnerability research. My goal is to combine technical depth with clear communication so each finding is easy to reproduce, understand and fix.
